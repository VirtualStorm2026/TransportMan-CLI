# TransportMan-CLI
A Simple, Python-based command line game about managing a public transport business.

# What is this?
Transport Manager CLI (Name in progress) is a simple Python-based game where you manage your own public transport company. It's a pretty basic gane with basic features.

# How do I install it?
Get the latest stable release in the Releases page, or get a experimental development build too if you want to give it a shot to upcoming features.

## Dependencies
To run the game, you will need these in order to play:

- Python 3

And you're ready to go.

# ⚠️ Experimental Stage
The game it's in a very early development stage, like, in an incredibly early stage. Only things that are available are:
-
- High Score system
- Save data system
- Basic debug functions
- Main menu
- Basic error handling (Most is catch-all error handling)

# Other things that you should be advised of
I'm a pretty basic Python developer. This is my first project and I feel pretty proud of it. And because of it, code optimization can be bad, or some things may fail constantly.

The game is in purpose made of only one Python file to keep it simple and ready to play in any device which supports Python.

Absolutely nothing of this project is made with AI. That's it. I wanted to add this just in case someone asks.
